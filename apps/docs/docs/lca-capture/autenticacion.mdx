# Autenticación requerida

Todos los endpoints requieren un token JWT válido en el encabezado `Authorization`:

```
Authorization: Bearer <token>
```

Para obtener este token, se utiliza el siguiente endpoint de autenticación:

## POST `/auth`

Este endpoint autentica aplicaciones o clientes externos a monitoriza.dtagro.es. Con las credenciales correctas del
cliente, el servicio devuelve un token JWT de acceso firmado.

### Parámetros

| Tipo   | Nombre         | Requerido | Descripción                                    |
| ------ | -------------- | --------- | ---------------------------------------------- |
| `body` | `clientId`     | SÍ        | Identificador único de la aplicación o cliente |
| `body` | `clientSecret` | SÍ        | Clave privada de autenticación para el cliente |

Para obtener el token JWT, se deben enviar siempre las siguientes credenciales estáticas:

<RedactedSecret
  id="lca-capture-auth-credentials"
  language="sh"
  redacted={`clientId: ••••••••
clientSecret: ••••••••`}
/>

> **Nota:** Estas credenciales son privadas y no deben exponerse en el código frontend.  
> Su uso está restringido a la consulta de datos (métodos GET) de la API de sensores.

### Ejemplo de solicitud

<RedactedSecret
  id="lca-capture-auth-request"
  language="http"
  redacted={`POST https://monitoriza.dtagro.es/api/acv/auth
Content-Type: application/json

{
  "clientId": "••••••••",
  "clientSecret": "••••••••"
}`}
/>

### Respuesta exitosa

Si las credenciales son válidas, devuelve un objeto JSON con el token JWT de acceso:

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

Este token debe incluirse en todas las peticiones a los endpoints bajo el prefijo `/api/acv`. Tiene una **validez de
30 minutos**: una vez caducado, las peticiones fallan con un error 401 y hay que solicitar un nuevo token en `/auth`
con el `clientId` y el `clientSecret`.

### Posibles errores

| Código                      | Causa                                      | Mensaje                                |
| --------------------------- | ------------------------------------------ | -------------------------------------- |
| `400 Bad Request`           | Falta `clientId` y/o `clientSecret`        | `Missing clientId and/or clientSecret` |
| `401 Unauthorized`          | Las credenciales del cliente son inválidas | `Invalid client credentials`           |
| `500 Internal Server Error` | Error interno del servidor                 | `Unable to authenticate client`        |
