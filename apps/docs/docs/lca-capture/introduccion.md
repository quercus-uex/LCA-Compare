# API Endpoints – Mediciones de sensores (ACV)

Esta API permite obtener los datos registrados por distintos sensores (**caudalímetro**, **fertilizante** y **tractor**).  
**Nota:** Si no se especifica un rango de fechas, se devolverán **todos los datos disponibles** para el sensor.

## Dirección URL base

Esta es la **dirección raíz** para todas las peticiones a la API de ACV.  
Todos los recursos disponibles se construyen a partir de este prefijo:

```
https://monitoriza.dtagro.es/api/acv
```
