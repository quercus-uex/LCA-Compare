# Introduction

**LCA Compare** is a web application for visualizing, comparing, and generating reports for the Life Cycle Assessment (LCA) of agricultural crops. LCA results are calculated by [LCA Bridge](https://github.com/quercus-uex/Ventum-OpenLCA-Service), a bridge service between the LCA Capture platform and the openLCA calculation engine using a database in .zolca format. Both services communicate through a shared Docker network.

## Features

- **Plot management** with SIGPAC, Catastro, and Portuguese property identifier integration for locating and geospatially representing polygons.
- **LCA result visualization** by plot and campaign, broken down into impact categories (fertilizers, crop management, pesticides, irrigation system, and total impact).
- **LCA comparator** between two crop sets, filtering by country, province, town, geographic location (radius in km), crop type, and campaign year.
- **PDF report generation** with a summary and recommendations generated by AI through OpenRouter.
- **JSON result export** for both reference and target sets.
- **Statistics dashboard** with global KPIs, time evolution, rankings by province and town, heat maps, impact profiles, and crop distribution.
- **Administration panel** for managing users, plots, crops, impact methods, countries, provinces, and towns.
- **JWT authentication** with automatic credential delivery by email on the first LCA calculation.

## Architecture

The application follows a client-server architecture with two distinct components:

| Component | Technology | Port |
|---|---|---|
| **Backend (REST API)** | NestJS 11 + Prisma ORM 7 | 3000 (internal) / 8080 (exposed) |
| **Frontend (SPA)** | React 19 + Vite 7 + TailwindCSS 4 + DaisyUI 5 | 80 |
| **Database** | PostgreSQL 17 + PostGIS | 5432 |

The backend exposes a REST API documented with Swagger/OpenAPI at `/docs`. The frontend is served through Nginx, which acts as a reverse proxy by routing `/api` requests to the backend and serving the SPA for all other routes.

## Technology Stack

### Backend

- **Node.js 22** with **NestJS 11**
- **Prisma ORM 7** on PostgreSQL with the **PostGIS** extension for geospatial data
- **JWT** for authentication
- **Swagger/OpenAPI** for API documentation
- **Playwright** for PDF generation
- **Handlebars** for report templates
- **Nodemailer** for email delivery
- **OpenRouter SDK** for AI integration
- **proj4** for coordinate transformations
- **argon2** for password hashing

### Frontend

- **React 19** with **TypeScript**
- **Vite 7** as bundler
- **TailwindCSS 4** + **DaisyUI 5** for styling
- **Leaflet / React-Leaflet** for interactive maps
- **React Router 7** for routing
- **React Hook Form** for forms
- **i18next / react-i18next** for interface internationalization
- **Recharts** for statistics dashboard charts
- **Sonner** for toast notifications
