# Introduction

**LCA-Compare** is a web application for visualizing, comparing, and generating reports for the Life Cycle Assessment (LCA) of agricultural crops. The results are calculated by [LCA Bridge](../openlca-bridge/introduccion.md) with openLCA; both services are deployed with the same Docker Compose file and communicate through its internal network.

## Features

- **Plot management** with SIGPAC, Catastro, and Portuguese property identifier integration for locating and geospatially representing polygons.
- **LCA results** by plot and campaign: the impact of each EF 3.1 category and its share across fertilizers, crop management, pesticides, and irrigation system.
- **LCA comparator** between a reference set and a target set, filtering by administrative or geographic location, own plots, crop type, campaign year, reference plots, or organization.
- **JSON and CSV export** of results and comparisons.
- **PDF reports** with a summary and recommendations generated by AI through OpenRouter.
- **Organizations** to analyze together the campaigns that other users consent to share.
- **Statistics dashboard** with global KPIs, time evolution, rankings by province and town, heat maps, impact profiles, and crop distribution.
- **Administration panel** for users, plots, crops, impact methods, and territorial data, and for viewing organizations and consents.
- **Automatic user creation**: when a user's first LCA calculation arrives, their account is created and, if email is configured, their password is sent to them.

## Architecture

| Component | Technology | Port |
|---|---|---|
| **Backend (REST API)** | NestJS 11 + Prisma ORM 7 | 3000 (internal) |
| **Frontend (SPA)** | React 19 + Vite 7 + TailwindCSS 4 + DaisyUI 5 | 80 (only published port) |
| **Database** | PostgreSQL 17 + PostGIS | 5432 (internal) |

The backend exposes a REST API documented with Swagger/OpenAPI at `/docs`. The frontend is served through Nginx, which acts as a reverse proxy by routing `/api` requests to the backend and serving the SPA for all other routes.

## Technology Stack

### Backend

- **Node.js 22** with **NestJS 11**
- **Prisma ORM 7** on PostgreSQL with the **PostGIS** extension for geospatial data
- **JWT** for authentication
- **Swagger/OpenAPI** for API documentation
- **Playwright** for PDF generation
- **Handlebars** for report templates
- **Nodemailer** for email delivery
- **OpenRouter SDK** for AI integration
- **proj4** for coordinate transformations
- **argon2** for password hashing

### Frontend

- **React 19** with **TypeScript**
- **Vite 7** as bundler
- **TailwindCSS 4** + **DaisyUI 5** for styling
- **Leaflet / React-Leaflet** for interactive maps
- **React Router 7** for routing
- **React Hook Form** for forms
- **i18next / react-i18next** for interface internationalization
- **Recharts** for statistics dashboard charts
- **Luxon** for dates
- **Sonner** for toast notifications
