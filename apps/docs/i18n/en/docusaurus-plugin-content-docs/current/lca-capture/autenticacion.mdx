# Authentication required

All endpoints require a **valid JWT token** in the `Authorization` header:

```
Authorization: Bearer <token>
```

To obtain this token, use the following authentication endpoint:

## POST `/auth`

This endpoint authenticates applications or clients external to monitoriza.dtagro.es. With the correct client credentials, the service returns a **signed access JWT token**.

### Parameters

| Type   | Name           | Required | Description                                    |
| ------ | -------------- | -------- | ---------------------------------------------- |
| `body` | `clientId`     | YES      | Unique identifier of the application or client |
| `body` | `clientSecret` | YES      | Private authentication key for the client      |

To obtain the JWT token, the following **static credentials** must always be sent:

<RedactedSecret
  id="lca-capture-auth-credentials"
  language="sh"
  redacted={`clientId: ••••••••
clientSecret: ••••••••`}
/>

> **Note:** These credentials are private and must not be exposed in frontend code.  
> Their use is restricted to data queries (GET methods) of the sensor API.

### Request example

<RedactedSecret
  id="lca-capture-auth-request"
  language="http"
  redacted={`POST https://monitoriza.dtagro.es/api/acv/auth
Content-Type: application/json

{
  "clientId": "••••••••",
  "clientSecret": "••••••••"
}`}
/>

### Successful response

If the credentials are valid, it returns a JSON object with the access JWT token:

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

This token must be included in all requests to the endpoints under the `/api/acv` prefix. It is **valid for 30 minutes**: once it expires, requests fail with a 401 error and a new token must be requested at `/auth` with the `clientId` and `clientSecret`.

### Possible errors

| Code                        | Cause                                    | Message                                |
| --------------------------- | ---------------------------------------- | -------------------------------------- |
| `400 Bad Request`           | Missing `clientId` and/or `clientSecret` | `Missing clientId and/or clientSecret` |
| `401 Unauthorized`          | The client credentials are invalid       | `Invalid client credentials`           |
| `500 Internal Server Error` | Internal server error                    | `Unable to authenticate client`        |
