# API Endpoints – Sensor measurements (LCA)

This API provides access to the data recorded by different sensors (**flowmeter**, **fertilizer**, and **tractor**).  
**Note:** If no date range is specified, **all available data** for the sensor will be returned.

## Base URL

This is the **root address** for all requests to the LCA API.  
All available resources are built from this prefix:

```
https://monitoriza.dtagro.es/api/acv
```
