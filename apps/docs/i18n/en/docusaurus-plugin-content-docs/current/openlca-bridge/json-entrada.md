# Input JSON for the `POST /capture-acv` Endpoint

The `POST /capture-acv` endpoint receives, as the request body, the crop output JSON generated by the **DTAgro** service. The full document structure is described below.

## General Structure

The JSON is composed of six main blocks:

| Block | Description |
|---|---|
| `metadatos` | Plot, crop, and user information. |
| `riegos` | Parameters of the installed irrigation system. |
| `bombeo` | Hydraulic pumping equipment data. |
| `fitosanitarios` | Applied plant protection products, with detail and grouping by SimaPro classification. |
| `fertilizantes` | Nutrient quantities and emissions associated with fertilization. |
| `manejo_cultivo` | Agricultural operations, land occupation, and water use. |
| `maquinaria` | Machinery used, including mechanized harvest. |

---

## `metadatos`

Contains the identifying data for the plot, crop, and user making the request.

### `metadatos.parcela`

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `integer` | Yes | Internal plot identifier in DTAgro. |
| `es_sigpac` | `object` \| `null` | Conditional | SIGPAC plot data. Required if the plot is registered in SIGPAC. |
| `es_sigpac.provincia` | `integer` | Conditional | INE province code. |
| `es_sigpac.municipio` | `integer` | Conditional | INE municipality code. |
| `es_sigpac.poligono` | `integer` | Conditional | Cadastral polygon number. |
| `es_sigpac.parcela` | `integer` | Conditional | Cadastral plot number. |
| `es_referencia_catastral` | `string` \| `null` | Conditional | Plot cadastral reference. Alternative to SIGPAC. |
| `pt_id_parcela_predial` | `string` \| `null` | Conditional | Property plot identifier (Portugal). Alternative to SIGPAC and cadastre. |
| `nombre` | `string` | Yes | Descriptive plot name. |

:::note
At least one of the three geographic identifiers (`es_sigpac`, `es_referencia_catastral`, or `pt_id_parcela_predial`) must be present. The service validates the plot using the first one it finds.
:::

### `metadatos.cultivo`

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `integer` | Yes | Internal crop identifier in DTAgro. |
| `tipo` | `string` | Yes | Crop type. Supported values: `"Tomate"`, `"Olivo"`, `"Vinedo"`. Determines the selected calculation process (`TomateProcess`, `OlivoProcess`, `VinedoProcess`). |
| `superficie_cultivada` | `number` | Yes | Cultivated area in hectares (ha). |
| `produccion` | `number` | Yes | Total production in kilograms (kg). |
| `consumo_agua` | `number` | Yes | Water consumption in cubic meters (m³). |
| `fecha_inicio_campania` | `integer` | Yes | Campaign start date in `YYYYMMDD` format. |
| `fecha_fin_campania` | `integer` | Yes | Campaign end date in `YYYYMMDD` format. |
| `ciclo` | `integer` | Yes | Crop cycle duration in days. |

### `metadatos.usuario`

| Field | Type | Required | Description |
|---|---|---|---|
| `id` | `integer` | Yes | Internal user identifier in DTAgro. |
| `nombre` | `string` | Yes | User name. |
| `email` | `string` | Yes | User email address. |

---

## `riegos`

Technical parameters of the irrigation system. Fields vary depending on the installed irrigation type.

| Field | Type | Description |
|---|---|---|
| `tipo` | `string` | Irrigation system type (for example, `"Sistema de riego horticola"`). |
| `entre_arboles` | `number` | Distance between trees in meters. |
| `entre_calles` | `number` | Distance between rows in meters. |
| `n_goteros_arbol` | `number` | Number of drippers per tree. |
| `n_arboles` | `number` | Total number of trees. |
| `n_calles` | `number` | Number of rows. |
| `m_portagotero` | `number` | Total meters of dripline pipe. |
| `peso_portagoteros_16mm` | `number` | Weight of 16 mm driplines in kg. |
| `n_enganches` | `number` | Number of couplings. |
| `peso_enganches` | `number` | Total coupling weight in kg. |
| `metros_principal` | `number` | Meters of main pipe. |
| `peso_principal_32mm` | `number` | Weight of the 32 mm main pipe in kg. |
| `peso_llaves` | `number` | Valve weight in kg. |
| `kg_PP` | `number` | Total kilograms of polypropylene (PP). |
| `peso_tira_pollo` | `number` | Weight of the poultry strip in kg. |
| `peso_principal_17mm` | `number` | Weight of the 17 mm main pipe in kg. |
| `deposito_abono` | `number` | Fertilizer tank capacity in liters. |
| `kg_PP_ha_anio` | `number` | kg of PP per hectare and year. |
| `kg_PE_1_ha_anio` | `number` | kg of polyethylene (type 1) per hectare and year. |
| `kg_PE_2_ha_anio` | `number` | kg of polyethylene (type 2) per hectare and year. |
| `kg_PE_deposito_ha_anio` | `number` | kg of tank PE per hectare and year. |
| `kg_PE_ha_anio` | `number` | Total kg of PE per hectare and year. |
| `kg_PVC_ha_anio` | `number` | kg of PVC per hectare and year. |
| `kg_PVC_produccion` | `number` | kg of PVC per kg of production. |
| `kg_PP_produccion` | `number` | kg of PP per kg of production. |
| `kg_PE_produccion` | `number` | kg of PE per kg of production. |

---

## `bombeo`

Hydraulic pumping equipment data associated with the irrigation system.

| Field | Type | Description |
|---|---|---|
| `cabeas` | `number` | Number of pumping heads. |
| `potencia` | `number` | Equipment power in kW. |
| `consumo_l_h` | `number` | Consumption in liters per hour. |
| `kg_acero_ha_produccion` | `number` | kg of steel per hectare and kg of production. |

---

## `fitosanitarios`

Plant protection products applied to the crop, with individual detail and grouping by SimaPro classification.

### `fitosanitarios.detalle[]`

Array with each applied plant protection product.

| Field | Type | Description |
|---|---|---|
| `id` | `integer` | Product identifier. |
| `nombre` | `string` | Product trade name. |
| `clasificacion_simapro` | `integer` | SimaPro classification code (determines the impact process in openLCA). |
| `n_aplicaciones` | `integer` | Number of applications performed. |
| `densidad` | `number` | Product density in kg/L. |
| `porcentaje_ma` | `number` | Declared active substance percentage. |
| `porcentaje_ma_usado` | `number` | Active substance percentage actually used. |
| `porcentaje_ma_personalizado` | `number` \| `null` | Custom percentage set by the user, if applicable. |
| `max_l_ha` | `number` | Maximum dose in liters per hectare. |
| `cantidad_total_ha` | `number` | Total amount applied per hectare in liters. |
| `cantidad_total_produccion` | `number` | Total amount applied per kg of production in liters. |

### `fitosanitarios.agrupado_por_clasificacion[]`

Array with plant protection products grouped by SimaPro classification.

| Field | Type | Description |
|---|---|---|
| `clasificacion_simapro` | `integer` | SimaPro classification code for the group. |
| `cantidad_total_produccion` | `number` | Total amount for the group per kg of production. |
| `fitosanitarios[]` | `array` | List of products in the group. |
| `fitosanitarios[].id` | `integer` | Product identifier. |
| `fitosanitarios[].nombre` | `string` | Product name. |
| `fitosanitarios[].n_aplicaciones` | `integer` | Number of applications. |
| `fitosanitarios[].cantidad_total_ha` | `number` | Amount per hectare in liters. |
| `fitosanitarios[].cantidad_total_produccion` | `number` | Amount per kg of production in liters. |

---

## `fertilizantes`

Quantities of applied nutrients and emissions associated with fertilization.

| Field | Type | Description |
|---|---|---|
| `kg_N` | `number` | kg of nitrogen (N) per kg of production. |
| `kg_K2O` | `number` | kg of potassium oxide (K₂O) per kg of production. |
| `kg_P2O5` | `number` | kg of phosphorus pentoxide (P₂O₅) per kg of production. |
| `kg_NH3` | `number` | kg of ammonia (NH₃) emitted per kg of production. |
| `kg_N2O` | `number` | kg of nitrous oxide (N₂O) emitted per kg of production. |
| `kg_NOX` | `number` | kg of nitrogen oxides (NOₓ) emitted per kg of production. |
| `kg_NO3` | `number` | kg of nitrate (NO₃) leached per kg of production. |
| `transporte_fert_UF_1` | `number` | Fertilizer transport unit factor (UF₁). |

---

## `manejo_cultivo`

Agricultural operations carried out on the crop, together with land occupation and water use data.

### `manejo_cultivo.labores[]`

Array with each agricultural operation performed.

| Field | Type | Description |
|---|---|---|
| `labor_simapro` | `string` | Name of the SimaPro process associated with the operation. |
| `rendimiento_h_ha` | `number` | Performance in hours per hectare. |
| `UF_1_ha` | `number` | Unit factor 1 per hectare. |
| `UF_1_ha_produccion` | `number` | Unit factor 1 per hectare and kg of production. |
| `fabricacion` | `number` | Machinery manufacturing impact. |
| `reparacion` | `number` | Machinery repair impact. |
| `UF_1_kg` | `number` | Unit factor 1 per kg of machinery. |
| `UF_1_kg_produccion` | `number` | Unit factor 1 per kg of machinery and kg of production. |

#### `manejo_cultivo.labores[].pases[]`

Array with each pass of the operation.

| Field | Type | Description |
|---|---|---|
| `id_pase_apero` | `integer` \| `null` | Implement pass identifier. |
| `apero_id` | `integer` | Implement identifier. |
| `apero_nombre` | `string` | Implement name. |
| `maquina_id` | `integer` | Tractor machine identifier. |
| `maquina_nombre` | `string` | Tractor machine name. |
| `pases` | `integer` | Number of passes performed. |
| `tiempo_m_labor` | `number` | Operation time in minutes per pass. |
| `rendimiento_h_ha` | `number` | Performance in hours per hectare. |
| `UF_1_ha` | `number` | Unit factor 1 per hectare. |
| `UF_1_ha_produccion` | `number` | Unit factor 1 per hectare and kg of production. |
| `fabricacion` | `number` | Manufacturing impact. |
| `reparacion` | `number` | Repair impact. |
| `UF_1_kg` | `number` | Unit factor 1 per kg. |
| `UF_1_kg_produccion` | `number` | Unit factor 1 per kg and kg of production. |

### Other `manejo_cultivo` Fields

| Field | Type | Description |
|---|---|---|
| `ocupacion_suelo` | `number` | Land occupation factor (m²·year per kg of production). |
| `uso_de_agua` | `number` | Water use in m³ per kg of production. |

---

## `maquinaria`

Machinery used in crop operations.

### `maquinaria.cosecha_mecanizada`

Array with mechanized harvest data, if applicable. It can be empty if the harvest is manual.

### `maquinaria.maquinas[]`

Array with each tractor machine used.

| Field | Type | Description |
|---|---|---|
| `id` | `integer` | Machine identifier. |
| `nombre` | `string` | Machine name or model. |
| `peso` | `number` | Machine weight in kg. |
| `vida_h` | `number` | Machine useful life in hours. |
| `rendimiento_h_ha` | `number` | Performance in hours per hectare. |
| `fabricacion_kg_ha` | `number` | kg of manufacturing steel per hectare. |
| `reparacion_kg_ha` | `number` | kg of repair steel per hectare. |
| `UF_kg_reciclaje` | `number` | Recycling unit factor in kg. |
| `UF_kg_reciclaje_produccion` | `number` | Recycling unit factor in kg per kg of production. |

---
