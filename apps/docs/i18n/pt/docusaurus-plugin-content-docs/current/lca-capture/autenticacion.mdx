# Autenticação requerida

Todos os endpoints requerem um **token JWT válido** no cabeçalho `Authorization`:

```
Authorization: Bearer <token>
```

Para obter este token, utiliza-se o seguinte endpoint de autenticação:

## POST `/auth`

Este endpoint permite a autenticação de aplicações ou clientes externos em monitoriza.dtagro.es. Com as credenciais corretas do cliente, o serviço devolve um **token JWT de acesso assinado**.

### Parâmetros

| Tipo   | Nome           | Obrigatório | Descrição                                   |
| ------ | -------------- | ----------- | ------------------------------------------- |
| `body` | `clientId`     | SIM         | Identificador único da aplicação ou cliente |
| `body` | `clientSecret` | SIM         | Chave privada de autenticação do cliente    |

Para obter o token JWT, devem ser enviadas sempre as seguintes **credenciais estáticas**:

<RedactedSecret
  id="lca-capture-auth-credentials"
  language="sh"
  redacted={`clientId: ••••••••
clientSecret: ••••••••`}
/>

> **Nota:** Estas credenciais são privadas e não devem ser expostas no código frontend.  
> A sua utilização está restrita à consulta de dados (métodos GET) da API de sensores.

### Exemplo de pedido

<RedactedSecret
  id="lca-capture-auth-request"
  language="http"
  redacted={`POST https://monitoriza.dtagro.es/api/acv/auth
Content-Type: application/json

{
  "clientId": "••••••••",
  "clientSecret": "••••••••"
}`}
/>

### Resposta bem-sucedida

Se as credenciais forem válidas, devolve um objeto JSON com o token JWT de acesso:

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

Este token deve ser incluído em todos os pedidos aos endpoints sob o prefixo `/api/acv`. Tem uma **validade de 30 minutos**: depois de expirar, os pedidos falham com um erro 401 e é necessário solicitar um novo token em `/auth` com o `clientId` e o `clientSecret`.

### Possíveis erros

| Código                      | Causa                                   | Mensagem                               |
| --------------------------- | --------------------------------------- | -------------------------------------- |
| `400 Bad Request`           | Falta `clientId` e/ou `clientSecret`    | `Missing clientId and/or clientSecret` |
| `401 Unauthorized`          | As credenciais do cliente são inválidas | `Invalid client credentials`           |
| `500 Internal Server Error` | Erro interno do servidor                | `Unable to authenticate client`        |
