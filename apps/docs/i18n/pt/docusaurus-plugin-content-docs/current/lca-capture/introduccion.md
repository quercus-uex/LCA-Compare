# API Endpoints – Medições de sensores (ACV)

Esta API permite obter os dados registados por diferentes sensores (**caudalímetro**, **fertilizante** e **trator**).  
**Nota:** Se não for especificado um intervalo de datas, serão devolvidos **todos os dados disponíveis** para o sensor.

## Endereço URL base

Este é o **endereço raiz** para todos os pedidos à API de ACV.  
Todos os recursos disponíveis são construídos a partir deste prefixo:

```
https://monitoriza.dtagro.es/api/acv
```
